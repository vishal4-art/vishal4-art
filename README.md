### ⚡ Featured Projects

**Electric Load Forecasting (Linear Regression)**
Forecasting model integrating historical electricity load with weather features — timestamp alignment, missing-value handling, and time-based feature engineering. Achieved **R² = 0.89**, **RMSE = 1298**, validated with MAE, MSE, and cross-validation.
🔗 [View notebook](https://colab.research.google.com/drive/1_KWEOaCbBs5zZwDZTUaB_rp36AmOyrxe)

**Generative AI Data-Analysis Agent**
Agentic assistant that answers natural-language questions on a CSV dataset by using the Claude API to generate pandas code, executing it in a sandboxed environment, and self-correcting via a plan → act → observe → revise retry loop. Includes an offline test harness to validate self-correction independent of live API calls.

**Demand Forecasting (First Quadrant Lab)**
End-to-end pipeline — extraction, cleaning, feature engineering, modeling — using regression and ensemble methods (Random Forest, XGBoost) on time-series data, compared via RMSE/R². Improved forecasting accuracy by **18%**, contributing to a **12%** operational cost optimization.
